# Discrete Math Toolkit in C++

A command-line toolkit for practicing and demonstrating core discrete mathematics concepts in C++.

## Planned Features

- Set operations
- Relation checking
- Function checking
- Euclidean algorithm
- Sequence calculations
- Matrix operations

## Project Structure

- `main.cpp` — program entry point and main menu
- `SetOperations.*` — set operations
- `Relations.*` — relation checking
- `Functions.*` — function checking
- `NumberTheory.*` — number-theory tools
- `Sequences.*` — sequence calculations
- `Matrices.*` — matrix operations

## Build

Using a C++17-compatible compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic *.cpp -o discrete-math-toolkit
```

## Run

On Linux or macOS:

```bash
./discrete-math-toolkit
```

On Windows PowerShell:

```powershell
.\discrete-math-toolkit.exe
```
