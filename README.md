# Discrete Math Toolkit in C++

A command-line C++ toolkit for practicing discrete mathematics.

## Features

- Set operations
- Relation and function checking
- Euclidean algorithm with displayed steps
- Arithmetic and geometric sequences
- 2x2 matrix operations

## Build and Run

```bash
g++ -std=c++17 -Wall -Wextra -pedantic *.cpp -o discrete-math-toolkit
```

```text
./discrete-math-toolkit
```

```powershell
.\discrete-math-toolkit.exe
```
