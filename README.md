# Discrete Math Toolkit in C++

A command-line toolkit for practicing and demonstrating core discrete mathematics concepts in C++.

## Planned Features

- Set operations
- Relation checking
- Function checking
- Euclidean algorithm
- Sequence calculations
- Matrix operations

## Project Structure

- `main.cpp` — program entry point and main menu
- `SetOperations.cpp` / `SetOperations.hpp` — set operations
- `Relations.cpp` / `Relations.hpp` — relation checking
- `Functions.cpp` / `Functions.hpp` — function checking
- `NumberTheory.cpp` / `NumberTheory.hpp` — number-theory tools
- `Sequences.cpp` / `Sequences.hpp` — sequence calculations
- `Matrices.cpp` / `Matrices.hpp` — matrix operations

## Build

Using a C++17-compatible compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic *.cpp -o discrete-math-toolkit
```

## Run

On Linux or macOS:

```bash
./discrete-math-toolkit
```

On Windows PowerShell:

```powershell
.\discrete-math-toolkit.exe
```
